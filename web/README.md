# Mishu Web para Lovable

Publica `web/index.html` como sitio estático HTTPS en Lovable o en un hosting compatible.

En Chrome/Edge de escritorio, pulsa **Seleccionar carpeta Mishu**. Puedes seleccionar una carpeta `mishu` existente o elegir una carpeta principal donde se creará `mishu`. Se crea `autosave.json`, que se actualiza tras cada cambio guardado.

**Limitaciones reales:** por seguridad los navegadores no pueden abrir carpetas automáticamente ni escribir en cualquier ruta sin permiso. Debes elegir la carpeta en cada sesión. Android y Safari pueden no ofrecer `showDirectoryPicker`; allí Mishu sigue guardando localmente en el almacenamiento del navegador, pero no garantiza escribir en una carpeta. No borres los datos del navegador sin exportar una copia.

El sitio web no ha sido publicado en lovable.dev: es un paquete listo para llevar a ese servicio.
